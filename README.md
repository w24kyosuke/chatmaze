# CHATMAZE

中国語チャット練習アプリです。「ソース（始まり）からシンク（終わり）へと流れる構造のカードデッキ」を使って、中国語の会話を定型文で反復練習できるゲームです。

## プロジェクトの目的
ユーザーが中国語の自然な会話フローを反復練習できるようにすることを目的としています。
デッキ（カード群）は、特定の会話状態（ノード）と、次の会話への選択肢（エッジ）からなる有向グラフを形成しています。すべてのノードがソースから到達可能であり、かつ必ずシンクで終わる構造（Source-Sink Structure）を持たせることで、途切れることのない自然な会話のキャッチボールを実現します。

## 主な機能
- **チャット機能**: ユーザーとシステムが中国語で会話を行います。次に出せる手札の候補（サジェスト）が表示されるため、初心者でも学習を進めやすくなっています。
- **フロー探索**: 会話の分岐や流れをMiller Columns（ミラーカラム）形式で視覚的に探索できます。
- **遷移マトリックス**: 会話カード間の遷移状態を一覧で確認し、フローの全体像を把握できます。

## セットアップと実行

### 依存関係のインストール
```bash
npm install
```

### 利用可能なスクリプト
- `npm run build`: デッキデータからアプリケーションで使用するデータを構築します。（`node scripts/build_deck.js`）
- `npm run test`: 構造テストを実行します。到達不能なノードや無限ループがないか確認します。（`./test.sh`）
- `npm run review`: 文脈テストを実行します。抽出された台本テキストをもとに意図した会話フローが自然に繋がっているか確認します。（`node test/extract_dialogues.js`）特定のカードにフォーカスする場合は `npm run review -- --focus <ID>` とします。

## 開発ガイドライン
本プロジェクトでは、デッキの拡張、機能追加、およびコードベースの保守において以下のルールを設けています。

1. **ソース・シンク構造と到達可能性の維持**
新しいカードや選択肢を追加する場合は、必ず「すべてのノードがソースから到達可能であり、かつ必ずシンクで終わる構造」を満たしているか検証します。
2. **会話の自然さの追求**
追加・修正する中国語フレーズは、ネイティブが使用する自然な表現を心がけます。会話を追加・修正した際は、必ず `npm run review` を実行し、前後の会話フローをセルフレビューします。
3. **拡張性を意識した設計とデータ構造**
データ（カード定義やグラフ構造）とロジック（画面描画やゲームの進行制御）は完全に分離します。
4. **UI/UXデザインの厳密な準拠 (Material Design 3)**
ユーザーインターフェースの実装やデザイン変更を行う際は、Material Design 3 (M3) の仕様（カラーシステム、タイポグラフィ、エレベーションなど）を厳格に守ります。
