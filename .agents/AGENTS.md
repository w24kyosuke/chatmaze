# エージェント指示書 (Agent Instructions)

本プロジェクトは、**「厳密な強連結成分をなすカードたちのデッキを使って、中国語の会話を定型文で練習できるゲーム」**です。
今後、AIエージェントを活用してデッキの拡張、機能追加、およびコードベースの保守を行っていきます。

AIエージェントとして本プロジェクトのコードやデータに変更を加える際は、以下のルールと方針を必ず遵守してください。

## 1. プロジェクトの基本目的と構造
- ユーザーが中国語の自然な会話フローを反復練習できるようにする。
- デッキ（カード群）は、特定の会話状態（ノード）と、次の会話への選択肢（エッジ）からなる有向グラフを形成する。

## 2. 厳守事項（Must-Haves）

### A. 「厳密な強連結成分」の維持
デッキの有向グラフは、常に**「厳密な強連結成分 (Strongly Connected Component)」**でなければなりません。
- **定義**: どのカード（状態）からスタートしても、選択肢を辿ることで、デッキ内の他のすべてのカードに必ず到達できる状態であること。行き止まり（出だしのないノード）や、一度入ると抜け出せない部分グラフ（シンク）が存在してはならない。
- **指示**: 新しいカード（ノード）や選択肢（エッジ）を追加・変更・削除する場合は、必ずグラフ全体が強連結成分の条件を満たしているかを論理的に検証し、満たさなくなるような変更は行わないこと（あるいは条件を満たすように他のエッジも同時に追加/修正すること）。

### B. 会話の自然さの追求
- 追加または修正する中国語のフレーズ（定型文）やその応答は、文脈として不自然でない、実際のネイティブが使用する自然な会話表現を心がけること。
- 前後のカードの繋がり（Q&Aの整合性、話題の遷移など）が論理的かつ自然であることを確認すること。

### C. 拡張性を意識した設計とデータ構造
- 今後AIが自動的にコンテンツを拡張しやすいように、データ（カードの定義やグラフ構造）とロジック（画面描画やゲームの進行制御）は完全に分離しておくこと。
- デッキデータは JSON などの機械可読性が高く、構造が明確なフォーマットで管理し、スキーマの一貫性を保つこと。
- コードベースに変更を加える際は、モジュール化を心がけ、他のコンポーネントへの副作用を最小限に抑えること。

## 3. 追加の推奨ガイドライン

- **変更時のテスト/検証**:
  デッキ構造を変更した際は、内部的に（あるいはスクリプト等を用いて）TarjanのアルゴリズムやKosarajuのアルゴリズムなどを想定したグラフの到達可能性チェックを行い、強連結性が壊れていないか確認するプロセスを思考に含めること。
- **コメントとドキュメント**:
  新しいロジックを追加した際や、複雑な会話の遷移を追加した際は、その意図が後続のAIエージェントや開発者に伝わるよう、簡潔なコメントを残すこと。
- **エラーハンドリング**:
  想定外のデータが読み込まれた場合（リンク切れなど）にゲームがクラッシュしないよう、適切なフォールバック処理やエラーログ出力の仕組みを維持・強化すること。
