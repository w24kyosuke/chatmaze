# 新規カード追加用テンプレート

## アイデア名: 
（例: レストランでの注文）

### 想定されるシチュエーション
（例: メニューを見て、店員におすすめを聞く場面）

### 新規ノード（カード）
- **ID:** (例: G1)
- **中国語:** (例: 有什么推荐的菜吗？)
- **ピンイン:** (例: Yǒu shénme tuījiàn de cài ma?)
- **日本語訳:** (例: おすすめの料理はありますか？)

### 接続元（どのカードから繋がるか）
- **元のノードID:** (例: B1) -> **選択肢のテキスト（中国語）:** (例: 看菜单 / メニューを見る)

### 接続先（どのカードへ繋がるか）
- **先のノードID:** (例: G2) -> **選択肢のテキスト（中国語）:** (例: 服务员的回答 / 店員の回答へ)
